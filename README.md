# Splatoonブキルーレット

Splatoon 3のブキをランダムに抽選する、PC向けの静的Webアプリです。

プレイヤーごとにブキを抽選する「プライベートマッチ」、4人分をまとめて抽選する「オープンマッチ」、全員が使うブキを1つ抽選する「ブキ統一」の3モードを利用できます。

公開サイト: https://ikkk129.github.io/splatoon-roulette-app/

## ユーザー向け

### 基本的な使い方

1. 画面上部から抽選モードを選びます。
2. プライベートマッチでは、抽選するプレイヤー数を指定します。
3. 必要に応じてブキリストから抽選対象を調整します。
4. 「抽選する」を押すと結果が表示されます。

プライベートマッチとオープンマッチでは、結果欄のプレイヤー名を直接編集できます。ブキ統一では、ブキ名とアイコンだけが表示されます。

### 抽選対象の変更

- ブキ名をクリックすると、そのブキを抽選対象に含めるか除外するかを切り替えられます。
- 各カテゴリの「すべて含める」「すべて除外」で、カテゴリ単位に変更できます。
- 「このモードのブキをすべて除外」「このモードの除外をすべて解除」で、現在のモード全体を変更できます。
- オープンマッチでは、表示中の結果をまとめて次回以降の抽選対象から外せます。

除外状態はモードごとに独立しています。あるモードで除外しても、別のモードの抽選対象には影響しません。

### データの保存と移行

ブキリストと除外状態はブラウザ内に自動保存されます。同じブラウザと端末であれば、ページを閉じても状態が維持されます。

- 「JSONを書き出す」: 現在のブキリストと除外状態をファイルに保存します。
- 「JSONを読み込む」: 書き出したJSONなどをアプリへ適用します。
- 「初期データに戻す」: ブラウザ内のデータを`weapon-list.json`の内容へ戻します。

ブラウザのデータを削除した場合や、別のブラウザ・端末を使った場合は保存状態を引き継げません。必要に応じてJSONを書き出してください。

### 配色

画面左下の配色ボタンから、Ink、Night、Forest、Blush、Cream、Skyを切り替えられます。

## 管理者・開発者向け

### 構成

ビルド処理や外部ライブラリを使わない静的サイトです。

```text
.
├── index.html                 # 画面構造
├── style.css                 # レイアウトと配色
├── script.js                 # 抽選・保存・入出力処理
├── weapon-list.json          # 初期ブキデータ
├── weapon-icons.js           # ブキ名と画像ファイル名の対応表
├── _images/
│   └── MainWeapons/          # ブキ画像
├── .nojekyll                 # GitHub Pagesで_imagesを配信するために必要
└── 要件定義.md               # 詳細要件
```

### ローカルでの確認

`fetch()`でJSONを読み込むため、`index.html`を直接開かず、リポジトリのルートをHTTPサーバーで配信してください。

例:

```bash
python -m http.server 4173
```

その後、`http://127.0.0.1:4173/`を開きます。Pythonを使用しない場合は、VS CodeのLive Serverなど任意の静的ファイルサーバーでも確認できます。

### 初期データの形式

`weapon-list.json`は次の形式です。

```json
{
  "version": 1,
  "items": [
    {
      "id": "weapon-unique-id",
      "name": "ブキ名",
      "category": "カテゴリ名",
      "excluded": {
        "multi": false,
        "four": false,
        "single": false
      }
    }
  ]
}
```

- `id`: 全項目で重複しない文字列
- `name`: 画面に表示するブキ名
- `category`: ブキリストでまとめるカテゴリ名
- `excluded.multi`: プライベートマッチでの初期除外状態
- `excluded.four`: オープンマッチでの初期除外状態
- `excluded.single`: ブキ統一での初期除外状態

`version`は現在`1`のみ対応しています。項目の追加・削除後は、IDの重複と各モードの`excluded`が真偽値になっていることを確認してください。

### ブキ画像の追加・変更

1. PNG画像を`_images/MainWeapons/`へ配置します。
2. `weapon-icons.js`へ、`weapon-list.json`のブキ名と画像ファイル名の対応を追加します。

```js
"スプラシューター": "Splattershot.png"
```

ブキ名は完全一致が必要です。ファイル名に空白を含めることはできますが、大文字・小文字や記号も実ファイルと一致させてください。対応する画像がない場合でも抽選はできますが、結果のアイコンは表示されません。

画像はページ表示後に低優先度で先読みされます。画像を増やす際は、初回通信量が大きくなりすぎないようファイルサイズを確認してください。

### ブラウザ保存の注意点

保存キーは`ink-draw-state-v1`です。保存済みデータがある場合、`weapon-list.json`よりブラウザ内のデータが優先されます。

初期データを更新しても既存利用者へ自動反映されないため、確認時は画面の「初期データに戻す」を実行するか、対象サイトのローカルストレージを削除してください。データ構造を変更するときは、保存済みデータの移行方法も検討してください。

### GitHub Pagesへの公開

このリポジトリは`main`ブランチのルートをGitHub Pagesで公開します。

```bash
git add -A
git commit -m "変更内容"
git push origin main
```

プッシュ後、公開サイトへの反映には少し時間がかかります。公開後は次を確認してください。

- トップページがHTTP 200で表示される
- `weapon-list.json`を読み込める
- `_images/MainWeapons/`内の画像がHTTP 200で表示される
- 抽選結果にブキ名とアイコンが表示される
- ブラウザのコンソールにエラーがない

`_images`はアンダースコアで始まるため、GitHub Pagesで配信するにはルートの`.nojekyll`が必要です。削除しないでください。

# Splatoonブキガチャ

Splatoon 3のブキをランダムに選ぶ、PC・スマートフォン向けの非公式ファンツールです。ブラウザだけで動作し、専用サーバーやアカウントは必要ありません。

公開サイト: [https://ikkk129.github.io/splatoon-random-weapon/](https://ikkk129.github.io/splatoon-random-weapon/)

## 使い方

1. 左側のサイドバーでモードを選びます。
2. 必要な場合はプレイヤー数を2〜10人から設定します。
3. 必要に応じてブキリストから抽選対象を調整します。
4. 「ガチャを回す」を押します。

プレイヤー名は結果カードへ直接入力できます。入力内容と抽選結果はページを再読み込みすると消えます。

### モード

- **プライベートマッチ**: 2〜10人分を抽選します。同じブキが重複する場合があります。
- **オープンマッチ**: 2〜4人分を抽選します。表示中のブキをまとめて次回の抽選対象から外せます。
- **ブキ統一**: 全員で使うブキを1つ抽選します。一度選ばれたブキは、このモードの次回抽選から自動で除外されます。

除外状態はモードごとに独立しています。たとえばプライベートマッチで除外したブキも、オープンマッチでは抽選対象のままです。

### ガチャアニメーション

サイドバーの「設定」でガチャアニメーションを切り替えられます。初期状態はOFFです。ONにすると、最初の切り替えをすぐに行い、ブキが7回切り替わった時点で抽選結果を確定します。

### ブキリスト

ブキリストは初期状態でカテゴリが閉じています。

- カテゴリ右端の矢印: そのカテゴリを開閉
- ブキリスト右上の矢印: 全カテゴリをまとめて開閉
- ブキカード: クリックしたブキの対象／除外を切り替え
- 「すべて含める」「すべて除外」: カテゴリ単位で切り替え
- 「このモードのブキをすべて除外」「このモードの除外をすべて解除」: 現在のモード全体を切り替え

除外中のブキはグレーの背景になり、画像が薄く、ブキ名に取消線が付きます。左側のステータスで対象数と除外数を確認できます。

### 設定

サイドバーの「設定」では、ガチャアニメーションのON/OFFを変更できます。設定はブラウザに保存され、次回起動時も引き継がれます。

### データ管理

サイドバー下部の「データ管理」から操作します。

- **JSONを読み込む**: ブキリストと除外状態を取り込みます。
- **JSONを書き出す**: 現在のブキリストと除外状態を保存します。
- **除外をすべて解除**: 3モードすべての除外を解除します。
- **初期データに戻す**: `weapon-list.json`の初期状態へ戻します。

ブキリストと除外状態、ガチャアニメーション設定はブラウザの`localStorage`へ自動保存されます。保存データが破損している場合は初期データで自動復旧し、画面に通知します。別の端末やブラウザへ移す場合はJSONを書き出してください。

## 開発者向け

ビルド不要の静的サイトです。HTML、CSS、JavaScriptのみで動作します。

```text
.
├── index.html
├── style.css
├── script.js
├── weapon-list.json
├── weapon-icons.js
├── 要件定義.md
├── .nojekyll
└── _images/
    ├── MainWeapons/
    ├── Gold-Capsule.png
    ├── Shell-Out-Machine.png
    ├── top-icon.png
    └── yajirusi.png
```

### ローカル起動

`weapon-list.json`を`fetch()`で読むため、`index.html`を直接開かずHTTPサーバーを使います。

```bash
python -m http.server 4173
```

[http://127.0.0.1:4173/](http://127.0.0.1:4173/)を開いてください。VS Code Live Serverなど、ほかの静的ファイルサーバーでも動作します。

### データ形式

`weapon-list.json`とインポート／エクスポートJSONは同じ形式です。

```json
{
  "version": 1,
  "items": [
    {
      "id": "weapon-unique-id",
      "name": "スプラシューター",
      "category": "シューター",
      "excluded": {
        "private": false,
        "open": false,
        "unity": false
      }
    }
  ]
}
```

- `version`は`1`のみ対応しています。
- `items`には1件以上必要です。
- `id`は空でない一意の文字列にします。
- `name`と`category`は空でない文字列にします。
- `excluded.private`、`excluded.open`、`excluded.unity`は真偽値にします。
- カテゴリとブキは`items`に記載した順で表示されます。
- JSONファイルは5MB以下にしてください。

旧タグの`multi`、`four`、`single`には対応していません。

### ブキ画像

ブキ画像は`_images/MainWeapons/`に置き、`weapon-icons.js`で表示名とファイル名を対応させます。

```js
"スプラシューター": "splattershot.png"
```

ファイル名は英小文字・数字・ハイフンのケバブケースに統一しています。GitHub Pagesはファイル名の大文字・小文字を区別するため、`weapon-icons.js`と実ファイルを完全一致させてください。対応がない場合も抽選はできますが、画像は表示されません。

ブキリストの画像はカテゴリを開いたときに遅延読み込みされます。初期表示で全画像を一括取得しない設計です。

### ブラウザ保存

- 保存キー: `ink-draw-state-v2`
- 保存対象: ブキリスト、各モードの除外状態
- 保存しないもの: プレイヤー名、抽選結果、選択中のモード、プレイヤー数

ガチャアニメーション設定は別キー`ink-draw-settings-v1`に保存され、保存データがない場合はOFFで起動します。

既存の保存データは`weapon-list.json`より優先されます。初期データ変更を確認するときは、画面の「初期データに戻す」を実行してください。

### 公開前チェック

1. ローカルサーバーで3モードの抽選を確認する。
2. 人数の最小・最大、除外、カテゴリ開閉を確認する。
3. JSONの読み込み・書き出し・初期化を確認する。
4. ブラウザコンソールにアプリ由来のエラーがないことを確認する。
5. 画像パスの大文字・小文字が一致していることを確認する。
6. `git status`で意図しないファイルが含まれていないことを確認する。

GitHub Pagesではリポジトリのルートを配信します。`_images`をJekyll処理から除外しないため、ルートの`.nojekyll`は削除しないでください。
